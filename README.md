# lieyuanyang.github.io

Personal academic website of Lieyuan Yang.

For complete upload, GitHub Pages, maintenance, and custom-domain instructions, see [PUBLISHING_GUIDE.md](PUBLISHING_GUIDE.md).

The site is built with [Quarto](https://quarto.org/) and renders to `docs/` for GitHub Pages.

## Build locally

```bash
quarto render
```

For GitHub Pages, publish from the `master` branch and the `/docs` folder.
